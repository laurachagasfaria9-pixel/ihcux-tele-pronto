#  Sobre o Projeto

O TelePronto é um aplicativo de telemedicina criado para reduzir a sobrecarga do pronto-socorro físico, permitindo que pacientes realizem triagem online, consultas por vídeo e gerenciamento de receitas digitais.

O protótipo foi desenvolvido em baixa fidelidade utilizando conceitos de UX e acessibilidade voltados principalmente para:

* idosos;
* pessoas debilitadas;
* usuários com baixa familiaridade tecnológica.

---

#  Objetivo

Criar uma interface simples, intuitiva e acessível para:

* realizar triagem médica;
* entrar em fila de atendimento;
* participar de consultas online;
* acessar prescrições digitais;
* configurar lembretes de medicação.

---

#  Telas Desenvolvidas

## 1. Tela de Chat IA

* Assistente inicial para suporte rápido;
* Campo de digitação simplificado;
* Interface limpa e objetiva.

## 2. Home / Dashboard

* Acesso rápido para:

  * triagem;
  * consultas;
  * medicamentos;
  * farmácias próximas;
* Navegação inferior fixa.

## 3. Consulta Online

* Interface de videochamada;
* Controles de câmera e microfone;
* Chat durante consulta;
* Botão de desligar.

## 4. Sala de Espera / Triagem Online

* Informação da posição na fila;
* Tempo restante;
* Botão de entrada na consulta.

## 5. Receitas e Medicamentos

* Visualização de receitas digitais;
* Organização dos medicamentos;
* Agendamento de horários dos remédios.

---

#  Análise de Acessibilidade

O sistema foi pensado para usuários que podem estar:

* com visão turva;
* cansados;
* ansiosos;
* com dificuldades motoras.

## Soluções aplicadas:

* Botões grandes;
* Alto contraste;
* Pouca informação por tela;
* Ícones simples;
* Navegação intuitiva;
* Campos amplos para toque;
* Estrutura limpa sem excesso visual.

Essas decisões ajudam a evitar confusão durante situações de mal-estar.

---

#  Fluxo Crítico

Fluxo principal para iniciar uma consulta:

1. Usuário acessa a Home;
2. Seleciona a opção “Triagem”;
3. Aguarda na fila virtual;
4. Entra na videochamada;
5. Recebe prescrição médica digital;
6. Agenda lembretes de medicamentos.

---

#  Prevenção de Erros

Para evitar erros críticos durante o uso:

* navegação simplificada;
* poucos elementos por tela;
* informações importantes destacadas;
* separação visual dos botões principais;
* status da consulta sempre visível;
* confirmação antes de encerrar atendimento.
